# Miner Monitoring (ESP32-WROOM-32 + W5500)

نسخه اولیه — **فقط خواندن**. هیچ فرمانی به ماینر ارسال نمی‌شود.

## نیازمندی‌ها
- Arduino IDE با **ESP32 core نسخه ۳.x** (Boards Manager → esp32 by Espressif)
- کتابخانه **ArduinoJson نسخه ۷.x** (Library Manager)
- Board: `ESP32 Dev Module`

## سیم‌کشی W5500

| W5500 | ESP32 |
|---|---|
| SCLK | GPIO 18 |
| MISO | GPIO 19 |
| MOSI | GPIO 23 |
| CS (SCS) | GPIO 5 |
| INT | GPIO 4 |
| RST | GPIO 16 |
| 3.3V | 3V3 |
| GND | GND |

سیم‌ها کوتاه، تغذیه ۳.۳ ولت پایدار (حدود ۱۳۰ میلی‌آمپر)، و کابل شبکه به همان سوییچ/روتری که ماینرها وصل‌اند.
پایه‌ها و همه‌ی تنظیمات ثابت (پیش‌فرض‌ها، محدودیت‌ها، زمان‌بندی) در `config.h` هستند.

## اولین اجرا
1. کد را آپلود کنید، Serial Monitor روی 115200.
2. IP اتریت در سریال چاپ می‌شود: `http://<IP>/` — کاربر `admin`، رمز `admin` (حتماً در تنظیمات عوض کنید).
3. اگر WiFi تنظیم نشده باشد، هات‌اسپات `minermonitor-XXXX` (نام از `DEVICE_NAME` در `config.h`) (رمز پیش‌فرض `minerscan`) باز می‌شود: `http://192.168.4.1/`.
4. در تب **تنظیمات** WiFi را وارد کنید، ذخیره و ری‌استارت کنید.
5. در تب **اسکن**، «رنج خودکار از شبکه» و «شروع اسکن».

سریال: `s` = شروع اسکن، `p` = چاپ جدول.

## نکات
- اسکن فقط روی **Ethernet** انجام می‌شود. WiFi فقط برای صفحه‌ی وب است؛ بهتر است در رنج IP متفاوتی از Ethernet باشد (در غیر این صورت صفحه هشدار می‌دهد).
- حداکثر ۶ اتصال موازی (محدودیت سوکت lwIP). رنج حداکثر ۱۰۲۴ آدرس.
- شناسایی با پورت **4028** (Whatsminer، Antminer/cgminer، Avalon) و **HTTP** (Bitaxe/NerdAxe و سایر).
- Whatsminer نسخه‌های جدید ممکن است API رمزنگاری‌شده داشته باشد؛ در آن صورت دستگاه «پیدا می‌شود ولی داده ندارد».
- فقط روی شبکه‌ی خودتان اسکن کنید.
- این نسخه روی سخت‌افزار واقعی تست نشده است؛ فقط Whatsminer M30++ منطق مشابه کد قبلی دارد.

## ساختار
| فایل | کار |
|---|---|
| `miner-scanner-w5500.ino` | راه‌اندازی شبکه، حلقه اصلی |
| `config.h` | **همه‌ی تنظیمات و پایه‌ها یک‌جا** |
| `settings.h` | خواندن/ذخیره‌ی تنظیمات در فلش |
| `devices.h` | لیست دستگاه‌ها |
| `probe.h` | اتصال TCP/HTTP و شناسایی برند |
| `detail.h` | خواندن اطلاعات هر برند (فقط خواندن) |
| `scanner.h` | اسکن LAN، خواندن دوره‌ای، جدول سریال |
| `web.h`, `webui.h` | API و صفحه‌ی وب |
